BTC500 outreach drafts — ready for the owner to send
=====================================================

Nothing in this folder has been sent, and the automation never sends it. Each
file is one recipient + one number + one link, written so the owner can paste it
into an email or a post in under a minute.

Naming: `<YYYY-MM-DD>-<recipient-or-channel>.txt`
Content: three short parts, no marketing voice.

  WHY THEM
  One sentence on why this specific person/publication would care.

  THE PITCH
  2-4 sentences with exactly one quotable number (the -84% drawdown, the
  14.4% cost of a late entry, the median -11.7%) and the URL it lives on.

  THE LINK
  https://btc500.net/... plus the anchor text you would want used.

Rules:
- Facts only, already published on the site, no claims that are not on the page.
- No bulk lists, no purchased links, no posting as the owner.
- If a file has been sent, move it to `sent/` and add the date sent.
- Delete drafts older than ~6 weeks that were never sent; stale pitches rot.

Start with the assets that already exist: /bitcoin-500-day-cycle#risk-heading
(the drawdown record) and #timing-heading (what a wrong entry date costs).
The machine-readable copy of every number is /data/500-day-cycles.json (shipped
2026-10-27, CORS open, rebuilt daily).
